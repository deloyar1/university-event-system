# Software Requirements ## Functional Requirements 1. Student Page — students can view profile, interests, and browse events 2. Organizer — organizers can create/manage events 3. Admin — admin can manage users and oversee the platform 4. Event Management — create, edit, delete events 5. Registration — students can register for events 6. Login — authentication for students, organizers, and admin 7. Matching Score — personalized event recommendation based on interest 8. Notification — alert students about relevant events ## Non-Functional Requirements 1. Security — secure authentication and data protection 2. Performance — fast load times, responsive UI 3. Usability — simple and intuitive interface for students 4. Reliability — system should work consistently without crashes 5. Scalability — should handle growing number of users/events 6. Maintainability — clean, modular code for easy future updates
